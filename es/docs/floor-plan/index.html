Desde Basic

Cargar el plano y ponerlo a escala

En el layout trabajas sobre el plano de planta de arquitectura. Cárgalo como DXF, PDF o imagen y dale la escala correcta, para que las longitudes y las superficies sean reales.

Más detalles

  • Cuanto más larga la distancia, más precisa la escala: usa una longitud total o una barra de escala, no el ancho de una puerta.
  • Si una distancia sale mal, toca otros dos puntos.
  • Con un DXF, Detect rooms encuentra automáticamente las estancias cerradas.
