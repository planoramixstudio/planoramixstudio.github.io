Fichiers du projet : enregistrer et ouvrir

Un projet vit dans des fichiers, dans un dossier que vous choisissez — pas dans le navigateur. Cette page explique quels sont ces fichiers et comment ne pas les perdre.

Mis à jour le 24 octobre 2026 · Version de l’application 494813a

Trois fichiers par projet

L’enregistrement crée côte à côte trois fichiers au nom du projet :

  • .proj — le projet lui-même. C’est la seule copie.
  • .task — les tâches et procès-verbaux du projet.
  • .data — les données du projet, séparées du modèle.

Enregistrer

Rien n’est enregistré automatiquement dans le navigateur. Sans enregistrement, tout est perdu à la fermeture de l’onglet. Enregistrez donc tôt, puis régulièrement, avec Ctrl+S ou l’icône d’enregistrement de l’en-tête.

Au premier enregistrement, le navigateur demande le dossier de destination. .task et .data sont écrits à côté du fichier .proj.

Ouvrir

Sur la page des projets, ouvrez un projet existant avec Ouvrir un dossier… : choisissez le dossier qui contient le fichier .proj.

Puis-je transmettre les fichiers ?

Oui. Transmettez le .proj avec .task et .data, pour que les tâches et les données suivent.

Que se passe-t-il si je ferme l’onglet sans enregistrer ?

Les modifications depuis le dernier enregistrement sont perdues. C’est pourquoi l’application demande, juste après la création d’un projet, s’il faut l’enregistrer.
